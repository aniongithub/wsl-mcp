Why?

AI agents on Windows need WSL. But they can't manage it — until now.

The problem

When AI agents work on Windows with WSL:

  • ✗ Run commands on the Windows host instead of WSL
  • ✗ Don't know which distros are available
  • ✗ Mix up Windows and WSL filesystem paths
  • ✗ No lifecycle management for distributions
  • ✗ Raw wsl.exe calls with no structure

The solution

Give the agent structured WSL access:

  • ✓ Discover and choose the right distro
  • ✓ Run commands inside any distribution
  • ✓ Read, write, and edit files in WSL
  • ✓ Install, export, import distributions
  • ✓ Full lifecycle: terminate, shutdown, configure

How it works

The agent discovers distros, runs commands, and manages files — all through MCP tools. You just approve.

20 purpose-built tools

Everything an agent needs to work inside WSL — structured, safe, complete.

One-line setup

Add to any MCP-compatible client.

{
  "mcpServers": {
    "wsl-mcp": {
      "command": "wsl-mcp",
      "args": ["serve"]
    }
  }
}
